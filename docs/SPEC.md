## サイト方針

### コンセプト
- 森本石油を**グループ全体のハブ**として位置づける
- 他3サイト（能登食いしん坊・千手院・EC）へのポータルを兼ねる
- **地域密着・人の温かみ**を前面に出したデザイン・コピー

### 技術方針
- 静的サイト（HTML / CSS / JS）
- WordPressは使用しない
- Git管理を徹底する
- コンテンツはMarkdownまたは直書きHTMLで管理

### デザイン方針（変更前サイトからの引き継ぎ・変更点）
- コンテンツはガッツリ変更（現サイトの構成は参考程度）
- 現サイトURL（参考）：https://kairinzan-senjuin.github.io/morimoto-sekiyu/
- 現サイトの良い点：シンプル、読みやすい、フルサービスの雰囲気が出ている
- 変更したい点：コンテンツ・コピー・写真・構成を刷新する
